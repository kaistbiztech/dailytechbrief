알리바바 '큐원4 맥스' 정식 출시…작업당 비용 67% 절감

알리바바가 '큐원4 맥스'를 정식 출시하며 실제로 계산에 쓰는 매개변수를 줄이고 가격도 낮춰, 작업당 평균 비용을 약 67% 낮췄다고 밝혔습니다.

무슨 일인가

알리바바 큐원팀은 16일 프리뷰 시작 5일 만에 큐원4 맥스를 정식 출시했습니다. 총 매개변수 2조 4,000억 개의 전문가 혼합(MoE) 구조로 전작 큐원3.8 맥스와 규모는 같지만, 실제 활성 매개변수는 950억 개에서 710억 개로 25% 줄였습니다.

아티피셜 애널리시스 종합 지능 지수는 43점(전작 34점)으로 키미 K3.1 프로(46점)보다 낮지만, 작업당 평균 비용은 10.02달러(약 1만 3,400원)에서 3.27달러(약 4,400원)로 약 67% 줄어 키미(3.68달러)보다 쌌습니다. 소프트웨어 개발 평가 딥SWE 1.1에서는 75.7점으로 앤트로픽 오퍼스 5.5(74.2점)를 앞섰습니다.

API 가격은 입력 100만 토큰당 1.50달러(약 2,000원), 출력 4.50달러(약 6,000원)로 전작보다 25% 내렸습니다. 모델 가중치는 공개하지 않았고, 큐원4 소형 모델은 오픈웨이트로 내겠다고 예고했지만 규모와 일정은 밝히지 않았습니다.

배경 — 왜 지금

작업당 비용이 크게 준 데는 토큰 단가 인하와 함께, 같은 작업을 더 적은 토큰으로 끝내게 된 효과가 겹쳤습니다. 토큰 사용량은 워크360에서 24~35%, 터미널벤치 4.0에서 약 48~49% 줄었습니다.

알리바바는 자동차 부품 제조에서 수작업 프로그래밍 시간을 약 475분에서 24분으로 줄인 사례 등을 소개했고, 사이버 공격 악용 데이터 걸러내기 등 안전 조치도 밝혔습니다.

왜 중요한가

산업

최고 성능 경쟁과 별도로 '같은 일을 얼마나 싸게 하느냐'가 AI 모델 경쟁의 주요 축이 되고 있다는 사례로 볼 수 있습니다.

일

AI를 업무에 붙일 때 토큰 단가만 볼 게 아니라, 작업 하나를 끝내는 데 드는 전체 비용을 비교하는 것이 더 정확할 수 있습니다.

생활

AI 비용이 내려가면 AI를 쓰는 서비스의 가격이나 무료 이용 범위에도 영향을 줄 수 있습니다.

어려운 말 풀이

매개변수(파라미터)
AI 모델이 학습으로 얻은 숫자 값들로, 모델 크기를 나타낼 때 씁니다.
전문가 혼합(MoE)
여러 '전문가' 부분 중 질문에 맞는 일부만 골라 계산하는 구조로, 전체 크기보다 실제 계산량(활성 매개변수)이 작습니다.
토큰
AI가 글을 처리하는 작은 단위로, 사용량과 요금을 셀 때 씁니다.
가중치 공개(오픈웨이트)
누구나 모델을 내려받아 직접 돌릴 수 있게 학습된 값을 공개하는 것입니다.
