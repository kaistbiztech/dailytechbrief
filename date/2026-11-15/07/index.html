LG AI연구원 'K-엑사원 2.5' API 무료 개방

LG AI연구원이 기술 검증 모델 'K-엑사원 2.5'의 API를 누구나 무료로 쓸 수 있게 열었습니다.

무슨 일인가

LG AI연구원은 11월 9일 코엑스에서 열린 '엔비디아 AI 데이 서울 2026'에서 K-엑사원 2.5 API를 공개했습니다. 8월에 공개한 독자 AI 파운데이션 모델(독파모) 2차 모델에 추가 학습을 한 기술 검증 모델입니다.

LG는 자체 분석 결과 24개 평가 지표를 합친 성능이 8월 모델보다 70% 넘게 올랐다고 밝혔습니다. 약 8주 동안 데이터 품질 개선, 사후 학습, 강화학습을 거쳤습니다.

개발자·스타트업·기업·연구기관 누구나 엑사원 개발자 사이트에서 API 키를 받아 서비스 개발과 연구에 무료로 쓸 수 있습니다.

배경 — 왜 지금

LG는 이 모델로 학습 방법을 다듬어 독파모 3차 모델에 적용하고, 2027년 1월까지 프런티어급 성능을 내는 것을 목표로 합니다.

에이전트 능력 비교에서 오토메이션 벤치 74.6점(딥시크 V4.1 플래시 74.9점), 클로 이밸 77.3점(딥시크 75.8점)을 기록했다고 밝혔습니다. 엔비디아 추론 소프트웨어 '다이나모' 도입도 검토하고 있습니다.

왜 중요한가

산업

국산 AI 모델이 무료 API로 열리면 국내 스타트업이 해외 모델 말고도 고를 수 있는 선택지가 늘어납니다.

일

성능 수치는 LG 자체 평가라, 우리 업무 데이터로 직접 써 보고 판단하는 것이 좋습니다.

생활

한국어에 강한 모델이 무료로 풀리면 이를 쓴 국내 서비스가 더 많이 나올 수 있습니다.

어려운 말 풀이

API
다른 프로그램이 AI 모델 기능을 불러 쓸 수 있게 열어 둔 연결 창구입니다.
독파모
정부가 지원하는 '독자 AI 파운데이션 모델' 사업의 줄임말입니다.
강화학습
AI가 잘한 답에 보상을 받으며 더 나은 답을 내도록 배우는 방법입니다.
