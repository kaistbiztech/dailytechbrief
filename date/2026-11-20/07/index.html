오픈AI, 'GPT-6.2 아스트라' 출시…API 20% 인하

오픈AI가 종합 지수 2위인 'GPT-6.2 아스트라'와 저가형 '솔'을 내놓고, 아스트라 API 가격을 20% 내렸습니다.

무슨 일인가

오픈AI는 17일(현지시간) 플래그십 모델 'GPT-6.2 아스트라'와 비용 효율형 'GPT-6.2 솔'을 공개했습니다. 지난 9월 말 내부 평가에서 문제가 발견돼 'GPT-6.1 아스트라' 공개를 취소한 지 약 50일 만입니다.

아티피셜 애널리시스 종합 지수에서 아스트라는 62점으로 2위였고, 1위는 앤트로픽 '클로드 페이블 5.2'(65점)였습니다. 솔은 57점으로, 이전 GPT-6 아스트라와 비슷한 성능을 작업당 비용의 약 15%로 냈다고 합니다.

아스트라 API 가격은 100만 토큰당 입력 8달러(약 1만 700원)·출력 40달러(약 5만 3,600원)로 기존보다 20% 낮아졌고, 캐시 입력은 1달러에서 0.40달러로 60% 내렸습니다. 솔은 입력 2달러·출력 10달러로 기존 가격을 유지했습니다.

배경 — 왜 지금

오픈AI는 두 모델 모두 자사 위험 평가 체계에서 사이버 보안 능력이 최고 위험 등급인 '크리티컬(Critical)'에 해당한다며, 고위험 보안 요청에 대한 제한과 감시를 강화했다고 밝혔습니다. 아스트라는 'AI 자기 개선' 분야 '높음(High)' 등급에 도달한 첫 외부 공개 모델이기도 합니다.

기사는 앤트로픽에 종합 성능 1위를 내준 상황에서도 오픈AI가 작업당 비용 효율에서는 우위를 확보했다며, 경쟁이 최고 성능에서 실제 업무 비용으로 옮겨가고 있다고 정리했습니다. 코딩 성능은 평가 기관마다 결과가 달랐습니다.

왜 중요한가

산업

1·2위 모델 간 점수 차가 좁아지면서, 가격과 작업당 비용이 모델 선택의 주요 기준이 될 수 있습니다.

일

문서·스프레드시트·법률 업무 성능을 강조한 만큼, 사내에서 쓰는 모델을 같은 과제로 다시 비교해 보면 비용을 줄일 여지가 있을 수 있습니다. 보안 관련 요청은 제한이 강화돼 결과가 달라질 수 있습니다.

생활

플러스·프로 등 유료 이용자는 '챗GPT 워크'와 '코덱스'에서 바로 쓸 수 있지만, 일반 채팅 기능에는 아직 적용되지 않았습니다.

어려운 말 풀이

API
다른 프로그램이 AI 모델을 불러 쓸 수 있게 열어 둔 연결 통로로, 쓴 만큼 요금을 냅니다.
캐시 입력
앞서 보낸 것과 같은 내용을 다시 보낼 때 저장해 둔 결과를 재활용해 더 싸게 처리하는 방식입니다.
크리티컬 등급
오픈AI 위험 평가 체계에서 가장 높은 위험 단계로, 강한 보호 조치가 필요하다는 뜻입니다.
