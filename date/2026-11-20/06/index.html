구글 '제미나이 4 네온' 공개, AI 분석 지수 3위

구글이 카본급 성능을 더 빠르고 싸게 내는 '제미나이 4 네온'을 내놨고, 아티피셜 애널리시스 지능 지수 61점으로 전체 3위에 올랐습니다.

무슨 일인가

구글은 18일(현지시간) '제미나이 4 네온'을 공개했습니다. 지난주 나온 카본·하이드로젠에 이은 모델로, 코딩·추론·에이전트 작업에서 상위 모델 카본과 비슷하거나 그 이상 성능을 더 빠른 속도와 낮은 비용으로 낸다고 소개했습니다.

컨텍스트 창(한 번에 읽을 수 있는 분량)은 100만 토큰이고, API 가격은 100만 토큰당 입력 3달러(약 4,000원)·출력 15달러(약 2만원)입니다. 하이드로젠보다 두 배 비싸지만, 11월 30일 할인이 끝난 뒤 아르곤·카본 가격(입력 4달러·출력 20달러)보다 25% 저렴합니다.

제미나이 앱에서 AI 프로·울트라 유료 구독자가 바로 쓸 수 있고, 기존 3.1 프로와 아르곤을 대체합니다. 모델 선택 메뉴에서는 '깊은 분석' 항목으로 들어갑니다.

배경 — 왜 지금

아티피셜 애널리시스 지능 지수에서 61점(최고 추론 설정)으로 전체 3위에 올라, 더 크고 느린 모델 바로 뒤에 자리했습니다. 이 밖에 코딩 에이전트 지수 1위(58.6), 자피어 자동화 평가 1위(56.3%) 등 여러 평가에서 상위권을 기록했다고 소개됐습니다.

구글은 네온이 복잡한 코딩, 분석적 추론, 기업 업무에 맞춰 만들어졌다고 설명했습니다. 제미나이 앱에서는 업로드한 스프레드시트·PDF를 더 정확히 읽고, 지메일·문서에서 정보를 끌어와 글을 쓰는 기능이 강화됐습니다.

왜 중요한가

산업

상위권 성능을 중간 가격대에 내놓는 경쟁이 붙으면서, AI 모델의 '성능 대비 가격' 기준이 계속 내려갈 수 있습니다.

일

API로 AI를 쓰는 팀이라면 같은 작업을 더 싼 모델로 처리할 수 있는지 다시 비교해 볼 만합니다. 특히 아르곤·카본 할인 종료(11월 30일) 전후로 비용이 달라질 수 있습니다.

생활

구글 AI 유료 구독자는 앱에서 별도 설정 없이 새 모델을 쓸 수 있어, 문서 정리나 영수증 확인 같은 일상 업무가 빨라질 수 있습니다.

어려운 말 풀이

컨텍스트 창
AI가 한 번에 읽고 기억할 수 있는 글의 양입니다. 100만 토큰이면 책 여러 권 분량입니다.
토큰
AI가 글을 처리하는 단위로, 대략 단어 조각 하나라고 보면 됩니다. API 요금은 토큰 수로 매깁니다.
아티피셜 애널리시스 지수
외부 평가 회사가 여러 시험 점수를 모아 AI 모델의 종합 지능을 비교한 점수입니다.

더 생각해 볼 점

  • 모델 이름(하이드로젠·아르곤·카본·네온)이 많아질수록 사용자는 어떤 기준으로 골라야 할까요?
  • 지수 1~2점 차이가 실제 업무 품질에서는 얼마나 체감될지 직접 비교해 볼 만합니다.
