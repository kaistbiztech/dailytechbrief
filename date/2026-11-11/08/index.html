구글 '제미나이 4 카본' 정식 출시…클로드 '페이블 5.2'의 4분의 1 가격

구글이 최상위 모델 '제미나이 4 카본'을 정식 출시했고, 할인 기간 API 가격은 앤트로픽 '클로드 페이블 5.2'의 4분의 1입니다.

무슨 일인가

구글은 11월 10일 공식 블로그에서 제미나이 4 카본을 개발자(구글 AI 스튜디오·안드로이드 스튜디오 유료 API), 기업('제미나이 포 비즈니스'), 최상위 유료 요금제 '구글 AI 울트라' 이용자에게 제공한다고 밝혔습니다. 10월 28일 공개 때는 '페어윈드' 프로그램의 일부 보안 전문가만 쓸 수 있었습니다.

API 가격은 100만 토큰당 입력 2달러(약 2,680원)·출력 10달러(약 1만3,400원)로 11월 30일까지 적용되고, 12월 1일부터 4달러·20달러로 오릅니다. 페이블 5.2는 8달러·40달러라 할인 기간엔 4분의 1, 인상 후엔 절반 수준입니다.

아티피셜 애널리시스(AA) 지능 지수는 페이블 5.2가 65점으로 1위, 카본 60점, 클로드 오퍼스 5.5 59점, GPT-6 아스트라 57점입니다. 재피어의 기업 업무 자동화 평가 '오토메이션벤치'에서는 카본이 성공률 53.88%·작업당 2.12달러(약 2,840원)로, 페이블 5.2(51.45%·4.64달러)보다 앞섰습니다.

배경 — 왜 지금

카본은 공개 당시 AA 지능 지수 1위였지만 11월 9일 페이블 5.2 출시로 1위를 내줬습니다. 구글은 커서벤치 4.0, 퍼플렉시티 WANDR, 오토메이션벤치에서 작업당 비용이 경쟁 모델의 절반 이하이면서 1위였다고 강조했습니다.

AI 코딩 플랫폼 '안티그래비티'에는 여러 에이전트가 일을 나누고 서로 검증하는 '/swarm' 기능이 시범 도입됐습니다. 다만 실제 업무 비용은 필요한 토큰 양과 재시도 횟수에 따라 달라질 수 있다는 지적도 있습니다.

왜 중요한가

산업

최상위 모델 경쟁이 성능 점수에서 '작업당 비용'으로 옮겨 가면서 가격 인하 압박이 커질 수 있습니다.

일

모델을 고를 때 토큰 단가보다 실제 업무 하나를 끝내는 데 드는 비용과 성공률을 함께 비교하는 것이 좋습니다. 할인가는 11월 30일까지라는 점도 계산에 넣어야 합니다.

생활

구글 AI 울트라 구독자는 제미나이 앱과 검색 AI 모드에서 카본을 차례로 쓸 수 있게 됩니다.

어려운 말 풀이

토큰
AI가 글을 처리하는 단위로, 단어 조각 정도의 크기입니다. API 요금은 토큰 수로 매깁니다.
API
다른 프로그램이 AI 모델 기능을 불러 쓸 수 있게 연결해 주는 통로입니다.
벤치마크
AI 성능을 같은 조건에서 비교하려고 만든 시험 문제 묶음입니다.
