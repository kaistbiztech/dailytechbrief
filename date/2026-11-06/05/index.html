오픈AI, 보안 특화 'GPT-6 사이버' 출시

오픈AI가 취약점 찾기와 공격 코드 작성에 특화된 'GPT-6 사이버'를 내놓고, 승인된 보안 고객에게만 제공하기 시작했습니다.

무슨 일인가

오픈AI가 현지시간 11월 5일 보안 특화 모델 'GPT-6 사이버'를 공개했습니다. 9월에 나온 'GPT-6 아스트라'를 바탕으로 취약점 발견, 공격 코드 개발, 침투 테스트에 맞춰 추가 훈련한 모델입니다. 공격 코드를 직접 써서 시험 환경에서 돌려 보고, 실패하면 다른 방법을 시도하며, 고치는 방법도 제안합니다.

로이터 보도에 따르면 리눅스 커널 취약점 1,724건을 재현해 948건에서 실제로 작동하는 권한 상승 공격 코드를 만들었습니다. 이전 모델 'GPT-5.6 솔'의 166건보다 5배 넘게 많고, 948건 중 588건은 알려지지 않았던 취약점이었습니다. 중요한 보안 문제 304건은 수정안과 함께 리눅스 개발자들에게 전달했습니다. 파이어폭스에서는 새로운 고위험 취약점 81건을 찾았습니다.

익스플로잇짐 평가에서 48.5%를 기록해 'GPT-5.6 사이버'(32.1%)보다 상대적으로 51% 나아졌습니다. 다만 '프론티어사이버' 평가에서는 288개 과제 중 90개를 풀어 GPT-6 아스트라(96개)에 못 미쳤습니다.

배경 — 왜 지금

오픈AI 자체 평가에서 이 모델의 사이버 보안 역량은 가장 높은 '심각(Critical)' 등급을 받았습니다. 그래서 오픈AI 보안 서비스 '데이브레이크' 중 공격 코드 개발 같은 고급 작업용인 '데이브레이크 레드' 고객에게만, 신원과 작업 권한을 따로 확인한 뒤 제공합니다. 허가된 작업 범위를 지킨 비율은 99.93%였습니다.

팔로알토 네트웍스·시스코·센티넬원 등 보안 기업이 이미 쓰고 있습니다. 오픈AI는 몇 주에 걸쳐 승인 고객 전체로 넓히고, 발전소·수처리 시설 같은 핵심 인프라 보안 담당자를 위한 전용 그룹도 만들 계획입니다. API 가격은 100만 토큰당 입력 20달러(약 2만 6,800원), 출력 100달러(약 13만 4,000원)입니다.

왜 중요한가

산업

취약점을 찾는 능력과 공격하는 능력은 같은 기술의 양면입니다. 같은 모델이 방어자에게는 강력한 도구가, 잘못 쓰이면 위협이 될 수 있어 '누구에게 어떻게 줄 것인가'가 AI 회사의 핵심 과제가 되고 있습니다.

일

보안 담당자라면 사람이 몇 주 걸리던 취약점 분석을 AI가 대량으로 해내는 시대를 준비해야 할 수 있습니다. 반대로 공격자도 비슷한 도구를 갖게 될 가능성을 염두에 두고 패치 속도를 높일 필요가 있습니다.

생활

리눅스나 파이어폭스처럼 많은 사람이 쓰는 소프트웨어의 숨은 구멍이 빨리 발견·수정되면 일반 사용자도 더 안전해질 수 있습니다. 소프트웨어 업데이트를 미루지 않는 습관이 더 중요해집니다.

어려운 말 풀이

취약점
해커가 악용할 수 있는 소프트웨어의 약점이나 구멍입니다.
권한 상승 공격
일반 사용자 권한으로 들어온 공격자가 관리자 권한까지 얻어 내는 공격입니다.
침투 테스트
허락을 받고 실제 해커처럼 시스템을 공격해 보면서 약점을 찾는 보안 점검입니다.
리눅스 커널
서버·안드로이드 등 수많은 기기에서 쓰이는 리눅스 운영체제의 핵심 부분입니다.
